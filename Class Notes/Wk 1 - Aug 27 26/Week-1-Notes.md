## 4. What AI actually is

> **Artificial intelligence is a capability — not a product.**

AI systems perform tasks that normally require aspects of human intelligence: **PERCEIVE · LEARN · REASON · GENERATE · DECIDE/ACT**

### The four questions a better manager asks

1. What task is being performed?
2. What evidence/data does it use?
3. What decision or workflow changes?
4. **What happens when it is wrong?**

> The label "AI" matters less than the capability and consequences.

## 5. Do not let the buzzword win — AI ≠ automation ≠ analytics

| | Behavior | Example | Type |
|---|---|---|---|
| **AUTOMATION** | Follows explicit instructions | "If invoice > $10K, route to manager." | Rules |
| **ANALYTICS** | Describes or explains data | "Revenue fell 8% in the Southwest." | Insight |
| **AI** | Infers patterns or generates output | "This customer has 82% churn risk." | Inference |

**Real systems often combine all three.**

### The vocabulary map (nested, not sequential)

```
ARTIFICIAL INTELLIGENCE — broad field: systems that perform intelligent tasks
  └── MACHINE LEARNING — systems learn patterns from data rather than only explicit rules
        └── DEEP LEARNING — multi-layer neural networks learn complex representations
              └── GENERATIVE AI — creates new text, images, audio, code, and more
```

## 8. Myth vs. reality checkpoint

| Myth | Reality |
|---|---|
| AI = ChatGPT | ChatGPT is one AI product; AI includes prediction, vision, recommendations, optimization, robotics, and more |
| Fluent = correct | A confident, polished answer can still be wrong. Output quality must be evaluated |
| AI is objective | Models can inherit bias from data, labels, objectives, and deployment choices |
| More automation = better | Automation can amplify a bad process or scale a small error into a large problem |

> Technology became easier to access at the same time that capability improved.

## 10. Part II — From AI capability to business value

> **An AI model creates no value by itself. Value appears when it changes a decision or workflow.**

### The business-value chain

```
DATA → AI CAPABILITY → DECISION → WORKFLOW → KPI → VALUE
(evidence) (inference/  (choice)   (action)  (measure) (outcome)
            generation)
```

**Worked example:** purchase history → churn prediction → retention offer → agent outreach → retained customers → recurring revenue

> ⚠️ **NO KPI = NO BUSINESS CASE.**

### Five patterns of AI business value

| Pattern | What it does | Metric family |
|---|---|---|
| **AUTOMATE** | Reduce repetitive effort | speed · cost |
| **AUGMENT** | Improve human decisions | quality · capacity |
| **PERSONALIZE** | Tailor at scale | conversion · loyalty |
| **DISCOVER** | Find patterns humans miss | risk · insight |
| **CREATE** | Generate new content/work | cycle time · experimentation |

**A strong use case usually names the value pattern and the metric.**

### AI is not a "tech department" topic

| Function | AI applications |
|---|---|
| Marketing | recommend · personalize · generate |
| Finance | forecast · detect fraud · explain |
| Operations | optimize · predict failure · schedule |
| HR | match skills · summarize · support |
| Customer | classify · retrieve · respond |
| Knowledge | search · summarize · draft |

> The differentiator is rarely "having AI." It is redesigning the workflow around it better than competitors.

## 11. Live demo — one customer problem, three AI approaches

**Customer message:** *"I was charged twice and support closed my ticket. If this is not fixed today, I am leaving."*
**Business goal:** resolve quickly while reducing churn and policy risk.

| Approach | What it does |
|---|---|
| **RULES** | Keyword "charged" → Billing queue |
| **PREDICT** | Churn risk = 0.86 → Priority = High |
| **GENERATE** | Draft empathetic response + next steps |

*Demo question:* what should the AI decide — and what should a human still control?

### Debrief — same problem, different capability, different risk

| | Behavior | Strength | Watch out |
|---|---|---|---|
| **Rules** | Deterministic | Easy to audit | Brittle |
| **Predictive ML** | Probabilistic | Scales decisions | Needs data + monitoring |
| **Generative AI** | Flexible | Handles language | Can hallucinate / vary |

> **Management question:** choose the least complex system that produces acceptable value and risk.

## 12. Limits every manager should anticipate

> **Powerful does not mean reliable.**

| Limit | Definition |
|---|---|
| **Hallucination** | Plausible but false output |
| **Bias** | Unequal outcomes |
| **Drift** | Performance changes over time |
| **Privacy** | Sensitive data exposure |
| **Security** | Manipulation / prompt injection |
| **Cost** | Compute, latency, operations |

### Responsible AI preview — capability ≠ permission

**CAN WE?** (technical feasibility) → **SHOULD WE?** (business / human consequences) → **WHO IS ACCOUNTABLE?** (governance + oversight)

*This question gets revisited in every major topic.*

## 14. Decision 01 — You are the executive

**A national retailer proposes an AI refund agent:**

| Metric | Value |
|---|---|
| Correct policy decisions | 95% |
| Average handling time | −48% |
| Estimated annual savings | $1.8M |
| Refund cases per year | 100,000 |

**Your decision:** DEPLOY / PILOT / REJECT — *vote first, explain second.*

### The twist — scale changes the risk

**5% error × 100,000 decisions = 5,000 potentially incorrect refund decisions per year.** Some errors involve high-value items and policy exceptions.

**Now what?**

| Control | Design |
|---|---|
| **Human review** | Route low-confidence / high-value cases |
| **Thresholds** | Automate only within safe limits |
| **Monitoring** | Track error *type*, not only accuracy |
| **Fallback** | Allow fast appeal / reversal |

> **Executive lesson:** model performance + error consequence + control design = deployment decision.
